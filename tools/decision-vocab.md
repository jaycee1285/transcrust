# Contextual dictation vocabulary

Example entries for `~/syncthing/john-vocab.md` (or `[vocabulary].path`).
This file is a template, not a runtime vocabulary source.
`description:` supplies the name's meaning; `ordinary:` describes its alternative.
`heard:` lists candidate spellings, never unconditional replacements under `--dec`.
The shared file reloads each dictation; habit/task entries stay excluded.
