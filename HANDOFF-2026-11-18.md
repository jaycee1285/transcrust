**Step 1, data (≤45 min). Verify licences and availability; don't assume.**
- **CMUdict:** check nixpkgs first (`nix search nixpkgs cmudict`). Otherwise the cmusphinx/cmudict
  `cmudict.dict` (BSD-style), or a Rust crate that bundles it. Pin its hash in a `SOURCES.md`.
- **Common-word frequency list,** top ~30–50k (e.g. wordfreq exports, or a Google n-gram top list).
  Check the licence, and pin it.
- **Feature table** for weighted distance: PanPhon's CSV if its licence fits AGPL, else a small
  hand-written ARPAbet feature matrix (voicing, place, manner; vowel height, backness, rounding).
  Cite the source either way.
- **Checkpoint:** the data files load, with counts printed.

**Step 2, one phone set (≤45 min).**
- Pick **ARPAbet** (CMUdict's native set).
- Map `espeak-ng --ipa -q` output to ARPAbet with an explicit table, logging any unmapped symbol
  loudly. Never silently drop one.
- Manual overrides from `john-vocab.md` win (`Gambol | G AE1 M B AH0 L`).
- **Checkpoint:** every vocabulary entry has phonemes plus their source (cmudict / espeak /
  override).

**Step 3, merger collapse as data, not code (≤30 min).**
- A `mergers.toml`, each rule with a comment and an example pair: cot=caught (AA/AO), Mary =
  marry = merry before R, pin=pen (IH/EH before N, M), father=bother, flapped T/D between vowels,
  dropped final R (an optional profile).
- **Profiles:** `us-general` now; `au` stubbed for bloey (trap–bath AE→AA before fricatives or
  nasal clusters, non-rhotic).
- **Unit tests:** cot/caught, merry/marry/Mary and pin/pen collapse equal; ship/sheep and cut/cat
  do **not**.
- **Checkpoint:** tests green.

**Step 4, distance (≤60 min).**
- Feature-weighted Levenshtein: substitution cost = feature distance; stress handled only on
  vowels.
- Plus a Kondrak-style n-gram (bigram/trigram) distance as a second column.
- **Tests:** identical → 0; Gambol vs gamble → 0 after the CMUdict lookup; Mater vs matter is
  small and nonzero; McQueen vs anything common is large.
- **Checkpoint:** a distance matrix printed for the 4 canon cases.

**Step 5, tiers and report (≤45 min).**
- For each entry, find its nearest frequent words (prefilter by length or n-grams; brute force
  is fine at this size).
- Tier: **0** if distance 0 after mergers, **1** if under the near threshold, **2** otherwise.
- **Set the near threshold once, from first principles, before looking at the results.** Don't
  tune it to make the canon come out right.
- **Output** `vocab-tiers.md` (human) and `vocab-tiers.json`: entry, phonemes and source,
  collapsed form, top-3 neighbours with distances, tier, and **the reason as a sentence**
  ("identical to 'gamble' after mergers").
- **Checkpoint:** the report.

**Step 6, acceptance (≤20 min).**
- Expected **without hints:** Gambol, Flo and Lightning tier 0; Mater tier 1; McQueen tier 2.
- If something misses, **report why** (a missing CMUdict entry? a merger rule? the threshold?)
  rather than patching until it passes. A wrong result plus a clear reason is acceptable output.

**Step 7, the bonus columns (≤30 min).**

- Run it on dayshade's verbs (`~/syncthing/dayshade/commands.md`) and Dragon's card verbs, as a

*before* the run. A session is a container that produces zero or more trials. This session
produced about 10, across several nodes:

- `synced-theme`: the theme audit (46 phone-parse failures).

Cleanup, docs and commits are not trials.

**Shape:**
- **Per node:** an append-only `trials.jsonl` beside `node.md` (id, date, node, predicted,
  changed, outcome, verdict supports/undercuts/neutral/broke-usefully, curveball, evidence path,
  artifact).
- **Where it touches:**
  - the node spec and templates;
  - a VaultAdd checkbox, for "worth saving, can't say why yet";
  - flownoter's parser;
  - a roll-up `trials` index built by a tree-walking daemon. Extend
    `~/repos/mobilelinks/internal/harvest/walk.go` (`WalkMarkdown` / `WalkLedgers`); don't write a
    new one.

**Check first / footguns (3):**
1. Only runs with a prediction recorded before results count. If you backfill tonight's runs, mark
   them `"predicted_after": true` rather than inventing predictions.
2. `trials.jsonl` lives in Syncthing and has several writers (phone, agents, laptop): one atomic
