# Correction pipeline — November 14

John and his son are trying live dictation. The requested slice is a usable
capture → transcription → decisions → correction → persistent learning loop,

## Changes in this slice

- Shared `correction::changes` retains every changed region, including long
  rewrites, punctuation, capitalization, whitespace, insertions and deletions.
  Large comparisons produce a complete fallback span, never a silent omission.
- Review displays every change. Remembering a glossary phrase is a separate,
  unchecked choice with editable Heard/Prefer fields. Up to 12 words/256 chars
  and numeric spellings can be learned. Commas/sentence punctuation still
  cannot be stored inside comma-separated glossary aliases; those edits remain
  visible and saved, with a smaller phrase available for explicit learning.
- Each new take has an ID shared by corpus WAV/JSON and state history.
  `~/.local/state/transcrust/history/<id>.json` retains the take after the next
  recording. `corrections.jsonl` in the parent directory retains every submitted
  correction, its complete changes and explicitly kept pairs before delivery.
  Corpus sidecars gain `corrected` without changing raw/injected/reference.
- Nemotron now starts on microphone press using the existing exact-audio tee.
  Decisions and injection still wait for stop. Empty/error results retain
  banked audio. Streaming caches and model weights are unchanged.
- `--wav ... --mode nemotron --dec --output-dir <dir>` now includes the actual
  decision path and emits Markdown plus `.replay.json` with raw/input/delivered,
  decision audit and original corpus metadata. `--paced` supplies 20ms audio
  chunks at microphone speed, reporting post-release ASR time for comparison.
